# aaron-lab

Build in public — mini tools & experiments by **Aaron**（独立开发者 · FDE）.

I build small, self-hosted tools in the open. **Every project runs as a public issue**: proposal → build log → delivery. Watch the process, use the results.

## What lives here

- Mini tools — usually single-container, zero-fuss, `docker run` to start
- Desensitized, self-owned rebuilds of patterns I ship in real client work — **no client data, ever**
- Honest build logs, including what broke

## The process

1. Proposal opens as an issue: goal / MVP boundary / acceptance criteria
2. Build happens in the open — progress logged in the issue
3. Delivery: code + README (+ demo where it makes sense)
